# 1-я лаба по сетям
* DHCP (Dynamic Host Configuration Protocol) - автоматическое получение ip, dns, маску и тд (67 и 68 порты)
* DNS (Domain Name System) - система доменных имен (таблица ip - domain) udp53 tcp53
* OSPF (Open  Shortest Path First) - основан на link-state узлов, роутеры объединены в граф, каждый узел знает список своих соседей и отклик от них, при передаче пакетов - алгоритм Дэйкстры
*  DORA используется DHCP для раздачи ip Discover (broadcast запрос в сети) Offer (ответ от хоста с временным выделением ipшника) Request (ответ от юзера с подтверждением принятия коннекта) Acknowledge (полноценное выделение ip, dns и тд)
* NAT (Network Address Translation) преобразование сетевых адресов, все пользователи из сети выхлдят в интернет с одного ipv4, для экономии этих самых портов
